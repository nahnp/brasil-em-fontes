# Segurança

Não publique vulnerabilidades exploráveis, dados pessoais, senhas ou tokens em issues e pull requests.

Para uma vulnerabilidade, utilize a opção **Report a vulnerability** na aba Security do repositório, quando disponível. O projeto habilita o recurso de comunicação privada do GitHub, sujeito à disponibilidade da plataforma. Não há promessa de recompensa ou prazo de atendimento.

Se o canal privado estiver indisponível, abra somente um pedido genérico de contato de segurança, sem detalhes da exploração. Não envie arquivos privados para o portal. Não existe formulário de denúncias anônimas nesta versão.
