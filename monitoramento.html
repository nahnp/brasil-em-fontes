Indicadores opcionais deste navegador

Ao ativar, registramos somente contagens de páginas, aberturas de links externos, cópias e compartilhamentos confirmados pela API do navegador. Dados ficam no armazenamento local deste dispositivo, sem envio ao servidor, sem IP, identificador de pessoa, parâmetros de URL ou conteúdo privado. Não representam visitas únicas nem audiência global. Limpar dados do navegador apaga os contadores.

Instalação e uso offline

Use “Instalar app”, quando disponível, ou o menu do navegador para adicionar à tela inicial.
